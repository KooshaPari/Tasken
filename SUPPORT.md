# Support

If you found a security issue, follow [SECURITY.md](SECURITY.md) — do not open a public issue.

For questions, usage help, or bug reports:
- Open a GitHub issue using the templates under `.github/ISSUE_TEMPLATE/`
- For general questions, use GitHub Discussions if enabled, otherwise a `question` issue

Commercial / paid support is not provided. This is a community-supported project.

If you need a fix urgently, opening a clear, minimal-reproduction issue (or a PR) is the fastest path.
