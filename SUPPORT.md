# Support

If you need help with Tasken, please use the following channels in order of preference:

1. **Bug reports and feature requests** — open an issue:
   <https://github.com/KooshaPari/Tasken/issues/new/choose>
2. **Questions and discussion** — GitHub Discussions:
   <https://github.com/KooshaPari/Tasken/discussions>
3. **Security issues** — follow `SECURITY.md` (do not open a public issue).

## Scope

Support is provided on a best-effort, community basis. There is no SLA.
For security vulnerabilities, see `SECURITY.md`.
